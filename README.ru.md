# SL Glass Film

[English](README.md) · **Русский**

Скилл для Claude Code, который создаёт ролики о продуктах в одном узнаваемом стиле: светлая сцена, матовое стекло, кинетическая типографика, выразительные переходы и звук, связанный с действием. Вы передаёте продукт и бриф, а агент собирает редактируемый проект Remotion и готовое видео.

## Стиль

[`sl-glass-film`](skills/sl-glass-film/SKILL.md) сохраняет визуальное направление, а продукт, сцены и длительность меняются под задачу:

- Холодная белая сцена с мягким синим и фиолетовым светом и тонкой сеткой точек.
- Матовые стеклянные карточки с полупрозрачной заливкой, светлыми краями, мягкими тенями и внутренним свечением.
- Плотные заголовки Inter Tight, появление слов через маску и один градиентный акцент в строке.
- Разные переходы между сценами: match cut, стеклянные шторки, вспышки, движение карточек и фирменная остановка времени.
- Музыка и эффекты, привязанные к истории и видимым действиям; озвучка по желанию.

Внутри есть [семь сюжетных схем](skills/sl-glass-film/references/stories.md), [шесть блоков сцен](skills/sl-glass-film/references/blocks.md), [правила стиля](skills/sl-glass-film/references/style.md), [переходы](skills/sl-glass-film/references/transitions.md), [руководство по звуку](skills/sl-glass-film/references/sound.md) и редактируемый [шаблон Remotion](skills/sl-glass-film/template/). Агент наполняет сцены материалами вашего продукта и проверяет готовый ролик. Поддерживаются форматы **16:9, 9:16 и 1:1**.

Этот репозиторий содержит только SL Glass Film. Другие стили могут появиться позднее в виде отдельных скиллов.

## Установка

Установите скилл в Claude Code через [skills CLI](https://github.com/vercel-labs/skills):

```sh
npx skills add SLtowl/sl-glass-film --skill sl-glass-film -g -a claude-code -y
```

Из локальной копии репозитория:

```sh
npx skills add . --skill sl-glass-film -g -a claude-code -y
```

Уберите `-g`, если скилл нужен только в текущем проекте. Можно также вручную скопировать всю папку [`skills/sl-glass-film`](skills/sl-glass-film/) в `.claude/skills/sl-glass-film/`. После установки начните новую сессию Claude Code.

## Использование

В Claude Code вызовите `/sl-glass-film` и опишите задачу:

```text
/sl-glass-film Сделай 20-секундный ролик 16:9 для запуска моего продукта.
Он помогает [аудитории] получить [реальный результат]. Покажи три
настоящие функции: [функция 1], [функция 2], [функция 3].
Используй мой логотип и скриншоты. Финальный призыв: [CTA].
Перед рендером предложи два-три сценария.
```

Агент предлагает сценарии, согласует текст озвучки при необходимости, собирает сцены из материалов продукта и передаёт MP4, постер и редактируемые исходники. Озвучка необязательна. Для вертикального или квадратного ролика укажите **9:16** или **1:1**.

## Требования

Claude Code с доступом к локальным файлам и терминалу; Node.js 18+, Chrome или Chromium, Python 3.10+, FFmpeg/ffprobe и пакеты из [requirements шаблона](skills/sl-glass-film/template/requirements.txt). Перед рендером нужно установить npm-зависимости шаблона. Аккаунт ElevenLabs требуется только при выборе этого источника голоса; также доступны edge-tts и вариант без озвучки.
